**踩坑记录**

- 本机解析到的版本偏新：`vite@8.3.1`、`typescript@7.0.2`。TS 7 **移除了 `baseUrl`**，
  `paths` 里的目标必须写相对路径 `./src/*`；`vite.config.ts` 里用 `node:url` 需要装
  `@types/node` 并把 `"node"` 加进 `tsconfig.json` 的 `types`。以上均已修好。
- 本机 PowerShell 禁止运行 `npm.ps1`，所有 npm 命令走 `npm.cmd`。
- 仓库级 git 身份为占位值 `campus-pixel-dev <campus-pixel-dev@localhost>`。
