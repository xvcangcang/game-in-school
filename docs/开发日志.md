## M1 · 核心层：类型 / 状态 / 存档 / 设置 / 路由（2026-01-01）

**做了什么**

- `game/types.ts`：全项目单一事实来源（属性、角色、事件、条件、效果、存档、设置、`SAVE_VERSION`）
- `app/rng.ts`：可播种随机数（mulberry32），**所有游戏随机必须走它**，保证剧情线可复现
- `app/store.ts`：60 行可订阅容器 `Store<T>` + 事件总线 `Bus<E>`
- `app/state.ts`：全局单例 `gameStore` / `settingsStore`（设置变更自动落盘）
- `app/settings.ts`：设置默认值与容错读写（坏数据自动回退默认值）
- `app/save.ts`：3 个存档位、结构校验、逐级版本迁移表、JSON 导入导出与下载
- `app/router.ts`：场景注册/切换/主循环，每个场景独占一块 overlay 并自动回收
- `data/`：外观部件表、性格表、身份表、预设 NPC 阵容
- `game/`：`character.ts`（建角色/好感分级/AI 描述）、`stats.ts`（初始属性/夹取/评分）、`newGame.ts`
- `render/canvas.ts`：320×180 舞台初始化 + 整数倍缩放 + `visualViewport` 兜底
- `scenes/boot.ts`：启动自检场景（存储 / 设置 / 随机数复现）；`scenes/menu.ts` 为 M3 占位
- `main.ts` 改为纯装配入口；新增 `styles/scenes.css`

## M2 · 像素渲染层 + 截图自查工具（2026-01-01）

**做了什么**

- `render/palette.ts`：调色板常量，与 `styles/global.css` 的 CSS 变量一一对应
- `render/pixelFont.ts`：3×5 点阵字模（**只有数字/大写字母/少量符号**，中文一律走 DOM）
- `render/sprite.ts`：16×24 程序化角色精灵。8 种发型 + 7 种配饰 + 5 套校服 + 6 种肤色 +
  三种朝向（front/side/back），按「外观+朝向」缓存到离屏 canvas；另提供 `drawPortrait`（半身立绘）、
  `drawSilhouette`（剪影）
- `render/tiles.ts`：6 个场景背景（教室/走廊/操场/食堂/家/办公室），全程序化绘制，支持夜晚压暗
- `render/ui.ts`：像素面板（硬边框+投影）、属性条、对话框框体、名牌、光标、气泡尾巴等
- `scenes/devArt.ts`：**开发用美术预览场景**，一屏看完所有部件与场景
  （地址栏 `#dev=art`，或在启动页点「美术预览」；方向键左右切场景，按钮切全员/立绘）
- `tools/screenshot.mjs`：驱动本机已装的 Edge 无头模式截图，**不下载浏览器**
  （新增 `npm run shot` 脚本），用于人工/AI 检查界面与像素美术

## M3 · 主菜单 / 设置 / 开局 / 存档 / 响应式（2026-01-01）

**做了什么**

- `ui/dom.ts`：`h()` 建元素工具（无框架但不必满屏 createElement）
- `ui/components.ts`：菜单列表（带键盘导航）、页面头、表单控件（输入/下拉/开关/滑杆）、
  提示条、卡片选择组
- `scenes/menu.ts`：正式主菜单（新游戏 / 继续游戏 / 角色工坊 / 事件图鉴 / 设置 / 关于），
  画面层是教室 + 五个同学，文字层是 DOM
- `scenes/newGameScene.ts`：选学段（初一/初二/初三）、难度、是否开 AI
- `scenes/settingsScene.ts`：文字速度、界面缩放、音效/BGM、**AI 配置**
  （启用开关、走代理还是直连、预设服务商一键填入、baseURL/model/Key、创造性、超时）
- `scenes/loadScene.ts`：3 个存档位的读取/导出/删除 + 导入同学的 .json 存档
- `scenes/aboutScene.ts`：玩法、操作、AI 说明、技术说明
- `scenes/stubs.ts`：里程碑占位场景工厂（creation / play / gallery 先用它接上路由）
- `styles/menu.css`：页面骨架、表单、卡片、存档位、提示条与响应式规则

**架构修正（重要）**

- 原来 `#overlay` 跟着画布一起缩放，导致 390×844 手机上界面只有 219px 高，完全没法用。
  本次改成**画面层与界面层解耦**：`#overlay` 铺满视口，画布只负责摆自己，
  竖屏时通过 CSS 变量 `--stage-h` 给界面留出顶部空间。详见 `docs/设计方案.md` 第 5 节。
- 顺带发现：绝对定位的 `.scene-overlay` 用 `inset:0` 会覆盖父级 padding，
  所以竖屏留白必须加在 `.scene-overlay` 上而不是 `#overlay` 上。

## M4 · 角色工坊：主角创建与 NPC 编辑（2026-01-01）

**做了什么**

- `app/roster.ts`：预设阵容的持久化（`cps:roster`）。逐条重建而不是直接信任 JSON，
  字段缺失/越界由 `createCharacter` + `clampAppearance` 兜住
- `ui/characterPreview.ts`：角色预览控件（正面 + 侧面小人 + 放大立绘），改部件即刷新

- `scenes/creation.ts`：**一个场景两种模式**
  - 新模式：① 姓名·性别·性格 → ② 捏外观 → ③ 确认阵容 → 开学（自动存到存档位 1 并进入 play）

- NPC 编辑器：身份（同学/老师/家人三组）、性格、好感滑杆、一句话人设、外观，
  以及删除与「恢复默认阵容」
- 所有编辑先落在 `draft` 里，只有点「开学」或「保存阵容」才落地，中途退出不污染数据

**修掉的 bug**

- 「下一步」按钮是灰的：它在 body 之外的 actions 栏里，姓名输入后不会重渲染。
