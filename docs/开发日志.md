## M6 · AI 集成：代理服务 / 事件生成 / NPC 对话 / 降级与熔断（2026-01-01）

**做了什么**

- `server/index.mjs`：**零依赖** Node 服务。静态托管 `dist/`（含单页回退与目录穿越防护）
  ＋ `POST /api/llm` 代理 ＋ `GET /api/health`。Key 只存在服务端，前端拿不到
- `server/.env.example`：`LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY` / `PORT` 模板
- `ai/client.ts`：模型调用唯一出口。支持「走本站代理」和「浏览器直连」两种模式，
  统一超时（AbortController）、统一错误码（NO_KEY / TIMEOUT / NETWORK / UPSTREAM / BAD_RESPONSE），
  并带 **熔断**：没配 Key 时不会每个时段都白发一次请求
- `ai/prompts.ts`：事件生成提示词（含题材边界与 JSON 结构）、NPC 对话提示词、连通性测试提示词。
  上下文里带上当前学段/时段/属性/人设/最近剧情，并要求不要重复最近出现过的事件标题
- `ai/schema.ts`：**安全底线**。结构错误整条丢弃；数值越界夹取、非法属性键与不存在的角色 id 直接剔除；
  一次改超过 4 项属性会被截断
- `ai/generator.ts`：草稿 → `GameEvent`；校验失败带上原因重试一次，仍失败返回 null 交给上层降级
- `ai/chat.ts`：NPC 自由对话（按角色保存会话历史）+ `pingAi()` 连通性测试
- `scenes/play.ts`：接入「AI 优先、失败静默降级」的主循环；
  新增「正在编剧情」动画、AI 内容角标、右上角「说话」按钮与聊天面板
- `scenes/settingsScene.ts`：「测试连接」按钮接真实请求
- `tools/mock-llm.mjs`：假模型服务，**不用真 Key、不烧额度**就能把整条 AI 链路跑通
- `README.md` 重写：区分「开发」「正式玩（含服务端 Key）」「纯静态分享」三种用法

**修掉的 bug**

- **熔断漏了"接口根本不是我们的代理"这种情况**：纯静态托管会把 `/api/llm` 回退成
  `index.html`（HTTP 200 + HTML）。原来这种"不是 JSON"被归为 `BAD_RESPONSE`，而它不触发熔断，
  结果每个时段都白发一次请求（实测 40 回合发了 41 次）。现在非 JSON 一律按连接问题处理，
  实测降到 1 次。`BAD_RESPONSE` 也给了 20 秒的短熔断。
- **等第与结局自相矛盾**：出现过「S 等第 + 普通人的三年」。改成等第跟着结局走。
- **图鉴详情里显示原始占位符**：没有进行中的对局时，正文直接显示 `{npc_math_teacher}`，
  看起来像 bug。为此把 `game/text.ts` 拆出「不依赖 GameState」的版本
  （`renderTemplateWith` + `NameResolver`），图鉴在没有对局时用预设阵容的人名来渲染。

**踩坑记录（下一位 AI 必看）**

- **不要用 PowerShell 改带中文的源码文件**。`Set-Content` 会按系统 ANSI 重新编码，
  整个文件的中文会变成乱码，而且 git 里还没有历史可回滚。改文件一律用 `edit` / `write` 工具，
  或者先把文件加进 git 再动。
