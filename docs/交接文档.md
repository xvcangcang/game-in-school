## 2. 铁律（改代码前务必确认）

1. **分层不可反向依赖**：`render/`、`data/`、`game/` 不得 import `scenes/`；
   `game/` 不得碰 DOM 和 Canvas。
2. **中文文本一律走 DOM 覆盖层**，不要往 Canvas 里画中文。
3. **AI 只能产出数据，不能直接改游戏状态**。所有 AI 输出必须过 `ai/schema.ts` 校验，
   校验失败 → 重试一次 → 仍失败则降级到本地事件库。
4. **游戏永不卡死**：任何 `await` 外部接口的地方都必须有超时和 catch 兜底。
5. **每完成一步就 `git commit`**，并在 `docs/开发日志.md` 追加一条、更新本文件第 4 节。
6. 提交前必须 `npm run typecheck` 通过。

## 3. 关键决策记录（ADR 摘要）

| 决策 | 结论 | 原因 |
| --- | --- | --- |
| 框架 | 不用 React/Vue | 依赖最少，长期维护不易被生态变更破坏 |
| 中文渲染 | Canvas 画图 + DOM 写字 | 汉字无法程序化生成像素字形；DOM 文本天然适配各尺寸 |
| 后端 | 零依赖 Node http 代理 | 只为托管静态资源 + 隐藏 API Key，不引入 express |
| 美术 | 全程序化生成 | 零素材依赖、零版权风险、体积小 |
| API 协议 | OpenAI 兼容 `POST {baseURL}/chat/completions` | 一套代码通吃 DeepSeek / OpenAI / Moonshot / 本地 Ollama |
| AI 定位 | 主力但不唯一 | 断网、超时、无 Key 时必须能靠本地事件库完整通关 |

## 5. 已知坑

- 本机 PowerShell 执行策略禁止 `.ps1`，脚本一律走 `npm.cmd` / `node`。
- 仓库级 git 身份是占位值，要换成自己的：`git config user.name "..."`。
- `index.html` 里 `#stage` 是 Canvas，`#overlay` 是 DOM 文本层，两者必须绝对定位重叠，
  `#overlay` 默认 `pointer-events: none`，只有可交互元素才开 `pointer-events: auto`。
- 画布内部分辨率固定 320×180，**不要**按设备像素比直接放大 Canvas 尺寸，
  要用 CSS 缩放 + `image-rendering: pixelated`。

### 版本相关的坑（TS 7 / Vite 8）

- **TS 7 已移除 `baseUrl`**。路径别名必须写成 `"paths": { "@/*": ["./src/*"] }`（相对路径）。
- `vite.config.ts` 里用 `node:url` 前，必须在 `tsconfig.json` 的 `types` 中加入 `"node"`。
- 提交前务必跑 `npm run typecheck`，上述两类错误只在类型检查时暴露。
