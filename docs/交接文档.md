## 2. 铁律（改代码前务必确认）

1. **分层不可反向依赖**：`render/`、`data/`、`game/` 不得 import `scenes/`；
   `game/` 不得碰 DOM 和 Canvas（这样它才能被脚本直接跑）。
2. **中文文本一律走 DOM 覆盖层**，不要往 Canvas 里画中文（点阵字模只有数字和 ASCII）。
3. **AI 只能产出数据，不能直接改游戏状态**。AI 输出必须过 `ai/schema.ts` 校验，
   校验失败 → 重试一次 → 仍失败则降级到本地事件库。**提示词不是安全边界，schema 才是。**
4. **游戏永不卡死**：任何 `await` 外部接口的地方都必须有超时、catch 和降级路径。
5. **不要用 PowerShell 改带中文的源码文件**（`Set-Content`、以及 `Get-Content -Raw` 往返，
   都会按 ANSI 重编码导致整个文件乱码；新文件在 git 里还没有历史可回滚）。
   **这条已经付过三次代价了**，一律用编辑器工具改。
6. **不要在鼠标事件里重建那个元素本身**。`createMenuList` 原来在 `mouseEnter` 里 `clear()`
   重建整个列表，光标下的按钮被销毁又新建 → 浏览器再派发一次 `mouseover` → 无限循环，
   表现是音效变机关枪。正确做法是只改 class（见 `syncActive()`）。
7. **音效改动请跑 `node tools/audiotest.mjs <url>`**。音频截图看不出来，只能靠计数，
   它会输出实际发声频率并自动判定是否合格。
8. **每完成一步就 `git commit`**，并在 `docs/开发日志.md` 追加一条、更新本文件第 5 节。
9. 提交前必须 `npm run typecheck` 通过。

## 3. 关键决策记录（ADR 摘要）

| 决策 | 结论 | 原因 |
| --- | --- | --- |
| 框架 | 不用 React/Vue | 依赖最少，长期维护不易被生态变更破坏 |
| 中文渲染 | Canvas 画图 + DOM 写字 | 汉字无法程序化生成像素字形；DOM 文本天然适配各尺寸 |
| 画面与界面 | **两层解耦**，`#overlay` 铺满视口 | 早期让 overlay 跟着画布缩放，手机上界面只剩 219px 高，没法用 |
| 后端 | 零依赖 Node http 代理 | 只为托管静态资源 + 隐藏 API Key，不引入 express |
| 美术 | 全程序化生成 | 零素材依赖、零版权风险、体积小 |
| API 协议 | OpenAI 兼容 `POST {baseURL}/chat/completions` | 一套代码通吃 DeepSeek / OpenAI / Moonshot / 本地 Ollama |
| AI 定位 | 主力但非唯一 | 断网、超时、无 Key 时必须能靠本地事件库完整通关 |
| 随机数 | 只用可播种的 `app/rng.ts` | 同种子 + 同选择 = 同剧情线，便于复现 bug |

## 6. 后续可做的方向（按性价比排序）

1. **内容量**：内置事件只有 64 条，一学期就能看掉大半。最划算的扩充方式是继续往
   `data/events/` 加条目——`common.ts` 里有大量现成格式示例，加完跑一次
   `npm run playtest` 即可验证
2. **结局收集**：`game/ending.ts` 的 `listEndings()` 已经列出全部结局，
   照 `app/gallery.ts` 的写法做一个「结局图鉴」很省事
3. **NPC 关系网**：目前只能表达「主角 ↔ NPC」的好感。可以给 `Character` 加
   `relations: Record<string, number>`，让同学之间也会闹矛盾（记得升 `SAVE_VERSION` 并写迁移）
4. **平衡性**：跑 `npm run playtest -- <url> 800` 看属性曲线。当前状态（200 回合随机选择）：
   学业 55 / 体力 99 / 心态 33 / 人气 100 / 老师好感 4。学业和心理压力已经合理，
   **体力和人气仍然容易顶满**，是下一步最值得调的：
   - 体力：`game/schedule.ts` 的每日恢复目前是 `+8`，可以再降，或者给事件加更多体力消耗
   - 人气：社交类事件的 `+popularity` 偏多，且缺少「人气高也会招麻烦」的反馈
   - 软上限在 `game/stats.ts` 的 `dampenGain()`，改常量即可全局生效
5. **可访问性**：`prefers-reduced-motion` 关掉打字机与音效；检查 Tab 顺序
6. **像素中文字体**：往 `public/fonts/` 放一份 OFL 授权的像素中文字体，
   在 `styles/global.css` 的 `--font-pixel` 里声明即可，**不用改任何逻辑代码**
7. **BGM**：`ui/audio.ts` 目前只有合成的方波音效，BGM 同样可以用 WebAudio 合成

## 7. 已知坑

- 本机 PowerShell 执行策略禁止 `.ps1`，脚本一律走 `npm.cmd` / `node`。
- 仓库级 git 身份是占位值，要换成自己的：`git config user.name "..."`。
- **TS 7 已移除 `baseUrl`**：路径别名必须是 `"paths": { "@/*": ["./src/*"] }`（相对路径）；
  `vite.config.ts` 里用 `node:url` 前要在 `tsconfig.json` 的 `types` 中加 `"node"`。
- `#stage` 是 Canvas，`#overlay` 是 DOM 文本层，两者**不再同尺寸**：
  overlay 铺满视口，竖屏时通过 CSS 变量 `--stage-h` 给界面留出顶部空间。
  注意绝对定位的 `.scene-overlay` 用 `inset:0` 会覆盖父级 padding，
  所以留白要加在 `.scene-overlay` 上。
- 画布内部分辨率固定 320×180，**不要**按 devicePixelRatio 放大 `canvas.width/height`，
  要用 CSS 缩放 + `image-rendering: pixelated`。
- `h()`（`ui/dom.ts`）的 children 里放 `null` 是安全的；但
  `element.replaceChildren(...)` 是原生 API，**传 null 会变成字符串 "null"**，
  一定要先过滤或用数组构建。这个坑在开发中出现过三次。
- 存档结构一改就要 `SAVE_VERSION + 1` 并在 `app/save.ts` 的 `MIGRATIONS` 里补迁移函数。
  目前 `SAVE_VERSION = 3`（1→2 补 Character.title，2→3 补 GameState.dayStartStats）。
- **事件文本里的 `{角色id}` 必须都能解析**。玩家能删掉预设 NPC，
  所以 `eventEligible()` 会扫描正文/选项里的全部占位符，引用了不在场的角色就不触发；
  AI 生成的内容只要引用了不存在的 id 也判不合法。改事件库时别写错 id。
